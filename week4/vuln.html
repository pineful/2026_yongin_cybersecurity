3개 다른 대역의 가상 네트워크
서로 다른 대역의 도커 컨테이너 가상 네트워크 환경 구성 방법을 조사한다
IP 범위까지 지정
네트워크 IP 범위까지 설정해서 컨테이너가 범위 내의 IP에 할당되는 방법을 조사한다
웹서비스 3개에 하나씩 적용
3개의 도커 컨테이너 웹 서비스에 생성했던 네트워크 대역들을 하나씩 적용한다
DONE무엇이 보이면 끝인가
8001 · 8002 · 8003 포트에 nginx 화면 세 개가 동시에 뜨고, inspect로 확인한 세 컨테이너의 IP가 서로 다른 대역이면 완료입니다.
정리

3개를 같은 방법으로
sudo docker network create --driver bridge \--subnet 172.100.1.0/24 --ip-range 172.100.1.0/24 \--gateway 172.100.1.1 custom-net1
옵션값뜻
--driver bridgebridge가상 스위치 형식으로 망을 만든다
--subnet172.100.1.0/24이 망이 쓸 대역
--ip-range172.100.1.0/24컨테이너에 나눠 줄 주소 범위
--gateway172.100.1.1대역의 출구 주소
custom-net1이름망 이름 · 옵션 뒤, 명령 끝에 온다

--ip로 대역 안의 주소를 고정한다

대역 안의 주소를 직접 지정

WHEN언제 쓰나
컨테이너를 다시 띄워도 같은 주소를 쓰고 싶을 때
자동 할당은 순서에 따라 주소가 바뀝니다
설정 파일에 상대 주소를 적어 둘 때
CAUTION무엇을 지키나
반드시 --ip-range 안의 주소여야 한다
같은 망의 다른 컨테이너와 겹치면 안 된다
대역 밖 주소를 주면 docker가 거부한다
--ip는 --net으로 붙인 사용자 정의 망에서만 쓴다 — 기본 bridge에서는 거부된다
